# Nexora Digital — projeto inicial

Site de apresentação para uma marca de desenvolvimento web, construído com HTML, CSS e JavaScript sem frameworks.

## Como abrir

1. Descompacta o ficheiro ZIP.
2. Abre a pasta no Visual Studio Code.
3. Abre `index.html` no navegador, ou usa a extensão **Live Server** para atualizar a página automaticamente enquanto editas.

## Estrutura

- `index.html` — conteúdo e secções do site.
- `styles.css` — cores, layout, tipografia e adaptação a telemóveis.
- `script.js` — menu mobile, ano automático e formulário demonstrativo.

## Antes de publicar

- Substitui `ola@oseudominio.pt` em `script.js` pelo email que vais usar.
- Confirma o nome da marca, o domínio e as redes sociais disponíveis.
- Atualiza serviços e textos para refletirem aquilo que consegues realmente entregar.
- Os três projetos de portefólio são conceitos fictícios. Mantém essa indicação ou substitui-os por trabalhos reais.
- O formulário usa `mailto:`: não armazena nem envia dados para uma base de dados. Para receber pedidos sem depender do programa de email do visitante, integra um serviço de formulários ou um backend.
- Testa em telemóvel, tablet e computador; verifica links, contraste, ortografia, carregamento e formulário.
- Configura domínio, alojamento, HTTPS, política de privacidade e informação legal adequada antes do lançamento público.

## Próximo passo recomendado

Personaliza primeiro o texto principal, o email de contacto e os três projetos de demonstração. Depois, aprende a publicar uma versão de teste e pede feedback a 2–3 pessoas antes de contactar clientes.
